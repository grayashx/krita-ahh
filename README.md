# Krita-based painting application

This repository is the foundation for an Android-first, adaptive digital painting application.

## Project direction

- Android-first mobile support with an adaptive phone, tablet, and desktop interface.
- Krita-derived painting technology.
- A hybrid brush system: retain Krita's proven brush engines while building a more versatile customization layer.
- An approachable ibisPaint-inspired workflow, implemented independently.
